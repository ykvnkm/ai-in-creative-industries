## Результаты

| Метрика | A (`d = 8`) | B (`d = 32`) | Δ | \|Δ\| > 2s | по допуску |
| --- | ---: | ---: | ---: | :---: | :---: |
| PSNR на тесте, дБ | 26,05 | 27,21 | +1,16 | да (2,10 s) | **улучшение** |
| разрыв train − test, дБ | 0,041 | 0,055 | +0,014 | нет | нейтрально |
| параметры, тыс. | 101,0 | 150,2 | +48,7 % | — (s = 0) | **ухудшение** |
| время обучения, с | 1,80 | 1,95 | +8,4 % | нет | нейтрально |
| эталон «средняя картинка» | 17,17 дБ | | выигрыш +8,88 / +10,04 дБ | | |

* гипотеза подтвердилась по параметрам (+49 176 весов, вычислено до запуска), разрыву и времени,
  но опровергнута по PSNR: ожидалось «нейтрально», получено +1,16 дБ — на 0,16 дБ больше допуска;
* класс PSNR неустойчив: интервал Δ ± 2·SE = [+0,46; +1,86] дБ пересекает границу ±1,0, при
  допуске ±1,5 дБ класс был бы «нейтрально»;
* диск круглый, центр без смещения (≤ 0,031 пикселя на 1024 тестовых сценах); радиус занижен на
  0,15 пикселя у A и на 0,05 у B — у `d = 32` край диска резче;
* развёртка по `d`: плато с `d = 3–4` (три фактора сцены), `d = 32` — 26,71 дБ;
* прогон преподавателя воспроизведён: эталон и параметры точно, средние PSNR — в пределах 0,14 s,
  классы по допуску совпали по всем метрикам; демонстрационный вариант 1 и его развёртка по `d`
  повторены (разность не больше 0,19 дБ).

## Как повторить

1. В Google Colab включить «Графический процессор T4», открыть
   `Яковенко_Максим_Михайлович_Вариант_2_ЛР_7.ipynb`.
2. Выполнить все ячейки по порядку. Первая ячейка создаёт рабочую папку `LR07` и при
   необходимости ставит пакеты; библиотека записывается из блокнота ячейкой `%%writefile`,
   её SHA-256 проверяется.
3. На T4 весь блокнот выполняется за 2–3 мин (30 обучений по 20 эпох и демонстрационный вариант).
4. Результаты пишутся в `artifacts/` рабочей папки: `comparison.png`, `samples.png`,
   `results.json`; последняя ячейка раздела 13 печатает их SHA-256. Обучение на GPU не побитово
   детерминировано: средние совпадут в пределах s, эталон и число параметров — точно.
