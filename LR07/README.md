## Как повторить

1. В Google Colab (GPU T4) открыть Python-блокнот и загрузить в него
   `Яковенко_Максим_Михайлович_Вариант_2_ЛР_7.ipynb`.
2. Выполнить все ячейки по порядку. Первая ячейка создаёт рабочую папку
   `LR07` и при необходимости ставит `torch` (сборка
   для CPU). Библиотека записывается из блокнота ячейкой `%%writefile`, загружать её
   отдельно не нужно.
3. Ожидаемое время — около минуты на GPU, 10–30 мин на CPU (30 обучений по 20 эпох); точный прогноз
   печатается после серии seed.
4. Результаты пишутся в `artifacts/` рабочей папки: `comparison.png`, `samples.png`,
   `results.json`; последняя ячейка печатает их SHA-256.
