## Результаты

| Метрика | A (AE) | B (VAE) | Δ | \|Δ\| > 2s | по допуску |
| --- | ---: | ---: | ---: | :---: | :---: |
| реконструкция, дБ | 26,65 | 26,27 | −0,38 | нет | нейтрально |
| интерполяция, дБ | 22,53 | 22,46 | −0,07 | нет | нейтрально |
| сэмплы, дБ | 12,84 | 23,19 | **+10,35** | да (18,9 s) | **улучшение** |
| R² факторов | 0,931 | 0,908 | −0,022 | нет | нейтрально |

* KL-член нужен для порождения из 𝒩(0, I), а не для интерполяции: коды обычного автокодировщика
  лежат далеко от 𝒩(0, I) (‖μ‖ ≈ 17 при норме сэмпла 2,7, разброс по осям до 7), у VAE — облако с
  разбросом ≈ 1, активных осей 6–8 из 8;
* исправление из указаний работает: сэмплы обычного автокодировщика из гауссианы, оценённой по
  его кодам, — 21,75 дБ вместо 12,84;
* гипотеза сбылась по реконструкции, интерполяции и сэмплам; не сбылась по R² (у AE выше, но в
  пределах допуска) и по критерию формы дисков на пути интерполяции (центр смещён на 1,1–1,4
  пикселя при пороге 1; двойных контуров почти нет);
* режим B совпал с режимом A демонстрационного варианта в пределах 0,1 дБ; классы и признаки 2s
  совпали с прогоном преподавателя по всем метрикам; демонстрационный скрипт выполнен как есть —
  таблица варианта 1 и диагностика совпали с указаниями до знака, схлопывание seed 102 без разогрева
  (17,2 дБ) воспроизведено. Во время демо в его файл, по-видимому, писали два процесса — см. журнал.

В окружении Engee не оказалось torch (окружение обновлялось после проверки указаний); в первой
ячейке скрипта ставится версия указаний, torch 2.4.1 для процессора — см. журнал.

## Как повторить

1. В Engee создать папку `LR08`, загрузить в неё `lab07_lib.py`, `lab08_lib.py`, `lab08_demo.py`
   (из `assignment/src` этой работы и ЛР №7), `src/lr08_variant2.py` и `artifacts/engee/LR08_2.ngscript`.
2. В первой ячейке скрипта заменить путь `W` на свою папку и выполнить все ячейки. Первая ячейка
   при необходимости ставит torch 2.4.1 (несколько минут), вариант 2 считается ~11 мин, демонстрационный
   скрипт — ~20 мин.
3. Обучение на процессоре не побитово воспроизводимо: средние совпадут в пределах 0,1–0,3 дБ,
   классы по допуску — точно.
