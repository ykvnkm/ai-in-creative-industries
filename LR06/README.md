## Результаты

| Метрика | A (512) | B (384) | Δ/A | \|Δ\|/s | \|Δ\| > 2s | по допуску |
| --- | ---: | ---: | ---: | ---: | :---: | :---: |
| сходство CLIP | 30,80 | 28,54 | −7,3 % (Δ = −2,26) | 1,58 | нет | ухудшение |
| энергия границ | 0,0457 | 0,0491 | +7,4 % | 0,49 | нет | нейтрально |
| контраст | 0,1923 | 0,2187 | +13,7 % | 1,17 | нет | ухудшение |
| время, с | 0,280 | 0,186 | −33,7 % | 23,42 | да | улучшение |

* на одном масштабе энергия границ в допуске (−2,6 % при 384); рост на исходном размере — эффект
  масштаба (+10,3 %), частично погашенный упрощением деталей;
* рост контраста целиком дал один кадр со светлым фоном (seed 104), без него −0,6 %;
* силуэт механической руки узнаваем на 5 кадрах B из 5, но при одном seed композиции 384 и 512
  разные;
* ответ на вопрос варианта: по правилу, записанному до запуска, кадр 384 как черновик чистового 512
  **не принимается** (CLIP и контраст вне допуска, хотя и в пределах разброса между seed);
  годится только для быстрого перебора идей; ответ устойчив к допуску от ×0,5 до ×2;
* демонстрационный вариант 1 воспроизведён: значения совпали с указаниями до 0,1 %, выводы — по всем
  четырём метрикам; `guidance_scale = 1,0` совпал с 0,0 бит в бит, PSNR при 3,0 — 11,61 дБ;
* гипотеза подтвердилась по времени, энергии границ на одном масштабе и узнаваемости объекта,
  опровергнута по CLIP, контрасту и энергии границ на исходном размере.

## Как повторить

1. В Google Colab (GPU T4) открыть Python-ноутбук `Яковенко_Максим_Михайлович_Вариант_2_ЛР_6.ipynb`
   и выполнить все ячейки по порядку. Первая ячейка создаёт рабочую папку
   `LR06`, делает её текущей и доустанавливает
   недостающие пакеты.
2. Библиотеки `lab05_lib.py` и `lab06_lib.py` записываются ячейками `%%writefile`;
   их SHA-256 сверяется с указаниями (`4eb17650…`, `c6d8473c…`).
3. На машине без GPU библиотеки адаптируются в памяти: `"cuda"` → `"cpu"`,
   вычисления в `float32`. Файлы на диске не меняются; замены печатаются.
4. Результаты — в `artifacts/` рабочей папки: `comparison.png`, `series_seeds.png`,
   `results.json`; их SHA-256 печатает последняя ячейка.

В Colab на T4 весь ноутбук выполнился за 8,1 мин; основное время — установка пакетов и первая загрузка
весов (≈ 3,3 ГБ), сами генерации заняли меньше минуты. На CPU — ориентировочно 15–25 мин.
