## Как повторить

1. В Google Colab (GPU T4) открыть Python-ноутбук `Яковенко_Максим_Михайлович_Вариант_2_ЛР_6.ipynb`
   и выполнить все ячейки по порядку. Первая ячейка создаёт рабочую папку
   `LR06`, делает её текущей и доустанавливает
   недостающие пакеты.
2. Библиотеки `lab05_lib.py` и `lab06_lib.py` записываются ячейками `%%writefile`;
   их SHA-256 сверяется с указаниями (`4eb17650…`, `c6d8473c…`).
3. На машине без GPU библиотеки адаптируются в памяти: `"cuda"` → `"cpu"`,
   вычисления в `float32`. Файлы на диске не меняются; замены печатаются.
4. Результаты — в `artifacts/` рабочей папки: `comparison.png`, `series_seeds.png`,
   `results.json`; их SHA-256 печатает последняя ячейка.

Ориентировочное время — несколько минут на GPU (15–25 минут на CPU), из них большая часть — воспроизведение
демонстрационного варианта (4 шага) и первая загрузка весов.
