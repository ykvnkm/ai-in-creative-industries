## Как повторить

1. В Engee создать папку `LR09`, положить туда `lab09_lib.py`, `lab09_llm.py`, `run_lr09.py` из
   `assignment/src` и `src/lr09_variant2.py`; скрипт Engee собрать из `src/LR09_variant2.jl` (ячейки
   разделены `# %%`) или взять `artifacts/engee/LR09_2.ngscript`. В первой ячейке заменить путь `W`.
2. Ячейка 1 ставит пакеты указаний; если в окружении transformers 4.x старше 4.57, ставится 4.57.6
   (команда указаний с `transformers<5` её не обновляет). Ячейка 2 считает вариант (~5 мин с загрузкой).
3. Часть 2: `python assignment/src/lab09_llm.py prompt <zero|few|step> 1` → новый чат → ответ в
   `answers/`; оценка — `python src/lr09_part2_score.py` из каталога `LR09`.
