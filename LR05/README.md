## Как повторить

1. В Google Colab (GPU T4) открыть Python-ноутбук `Яковенко_Максим_Михайлович_Вариант_2_ЛР_5.ipynb`.
   Первая ячейка создаёт рабочую папку `LR05` и ставит
   недостающие пакеты; путь заменить на свой.
2. Выполнить все ячейки по порядку. Библиотека `lab05_lib.py` записывается ячейкой
   `%%writefile`, её SHA-256 сверяется с указаниями (`4eb17650…`, 6447 байт).
3. Без GPU библиотека исполняется с заменой `"cuda"` → `"cpu"` и float16 → float32;
   файл библиотеки при этом не меняется, замены выводятся ячейкой и пишутся в манифест.
4. Для проверки в новом сеансе перезапустить ядро и выполнить ноутбук ещё раз: базовый
   запуск попадёт в `artifacts/run_002/` и будет сверен с `run_001`.
5. Перед скачиванием ноутбука нажать «Сохранить», иначе выходы в файл не попадут.

Ожидаемое время — несколько минут на GPU (5–20 мин на CPU); веса модели (≈ 2,6 ГБ) скачиваются с Hugging Face
без авторизации.
