## Результаты

| Величина | Значение |
| --- | --- |
| SHA-256 A / B | `403134b8e34029d1…` / `098ebd438eb3befe…` |
| совпадение пикселей / максимум различия | нет / 254 |
| PSNR | **10,63 дБ** — вердикт **different** (прогноз 8–15 дБ) |
| повтор со свежим генератором | SHA-256 совпал |
| новый сеанс (среда создана заново) | SHA-256 A и B совпали с первым сеансом |
| готовый шум через `latents`, без генератора | воспроизводит A и B бит в бит |
| общий генератор на два вызова (ошибка) | второе изображение другое, PSNR 9,25 дБ |
| демо преподавателя, seed 20260919 | `7daa342a…` ≠ `ac45a7ba…` из указаний (torch +cu130 против +cu128) |

* гипотеза подтвердилась полностью: seed + 1 даёт другой начальный шум, а при одном шаге
  sd-turbo изображение почти целиком определяется шумом;
* причина различия проверена отдельным экспериментом: шум seed 1002 и 1003 не коррелирован
  (−0,0018), и только он отличает A от B;
* на обоих изображениях механическая рука узнаётся и остаётся главным объектом, палитра
  синий/янтарный сохранена; вместо силуэта модель рисует объёмную конструкцию;
* побитовая воспроизводимость доказана только для этой среды: та же T4 с другой сборкой
  CUDA даёт другие байты.

## Как повторить

1. В Google Colab (GPU T4) открыть ноутбук `Яковенко_Максим_Михайлович_Вариант_2_ЛР_5.ipynb`.
   Первая ячейка создаёт рабочую папку `LR05` и ставит недостающие пакеты.
2. Выполнить все ячейки по порядку. Библиотека `lab05_lib.py` записывается ячейкой
   `%%writefile`, её SHA-256 сверяется с указаниями (`4eb17650…`, 6447 байт).
3. Без GPU библиотека исполняется с заменой `"cuda"` → `"cpu"` и float16 → float32;
   файл библиотеки при этом не меняется, замены выводятся ячейкой и пишутся в манифест.
   SHA-256 на этом пути с GPU не сопоставимы.
4. Для проверки в новом сеансе удалить среду выполнения, создать новую и выполнить ноутбук
   ещё раз: ячейка после базового запуска сверяет SHA-256 с первым сеансом.
5. Перед скачиванием ноутбука нажать «Сохранить», иначе выходы в файл не попадут.

Время — около 4 мин на T4 вместе со скачиванием весов (≈ 2,6 ГБ, с Hugging Face без
авторизации); на CPU — 5–20 мин.
