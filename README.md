# Искусственный интеллект в креативных технологиях

Лабораторные работы курса. Каждая работа — один Jupyter-ноутбук, в котором
подряд идут код, фактические выходы его выполнения и отчёт, плюс полученные
артефакты с манифестами.

Автор: [@ykvnkm](https://github.com/ykvnkm)

## Как это устроено

```
LR0N/
├── LR0N.ipynb      код + сохранённые выходы + отчёт
├── README.md       что это и как повторить
├── assignment/     методические указания
├── configs/        параметры запуска одним файлом
├── artifacts/      результаты: файл + manifest.json рядом
└── reports/        environment.txt и сравнения
```

Каталоги `configs/`, `artifacts/` и `reports/` создаёт сам ноутбук при выполнении.

**Правила, которые соблюдаются во всех работах:**

1. Все параметры эксперимента — в одном конфиге, а не зашиты по месту в коде.
2. Рядом с каждым результатом лежит `manifest.json`: модель, полная ревизия,
   входные данные, seed, параметры, устройство, dtype, версии библиотек, SHA-256.
3. Ревизия модели фиксируется всегда — имя без ревизии указывает на подвижный снимок.
4. Веса моделей и виртуальное окружение не коммитятся, они восстанавливаются
   по конфигу и `environment.txt`.
5. Отрицательный результат фиксируется, а не прячется: расхождение контрольных
   сумм и воспроизведённая ошибка — такие же артефакты, как картинка.

## Инструменты

Курс допускает engee.com, Hugging Face, Ollama и OpenCLAW. Фактически
использованная площадка указывается в ноутбуке каждой работы.

## Лицензии

Код учебный. Веса моделей распространяются на условиях своих лицензий, они
указаны в соответствующей работе. Сгенерированные изображения — учебные
концепты, они не документируют реальные объекты и события.
