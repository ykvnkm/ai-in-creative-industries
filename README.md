# Искусственный интеллект в креативных технологиях

Репозиторий лабораторных работ курса. Для каждой работы хранятся постановка задачи,
исходный код, конфигурация запуска, полученные артефакты, журналы среды и отчёт.
Цель организации репозитория — не хранение картинок, а **возможность независимо
повторить любой запуск** и проверить происхождение каждого артефакта.

Автор: [@ykvnkm](https://github.com/ykvnkm)

## Структура репозитория

```
.
├── README.md            навигация по курсу
├── CONVENTIONS.md       соглашения: структура работы, именование, что коммитить
├── .gitignore           venv, кэш весов моделей, секреты, служебные файлы ОС
├── _template/           заготовка новой лабораторной работы
└── LR01/                лабораторная работа №1
```

Структура каждой работы одинакова и повторяет схему из методических указаний:

```
LR0N/
├── README.md            что это за работа и как повторить запуск
├── REPORT.md            отчёт по обязательной структуре
├── MANIFEST.sha256      контрольные суммы всех сдаваемых файлов
├── assignment/          методические указания
├── data/                описание входных данных (prompt, его происхождение)
├── src/                 исходный код
├── configs/             параметры запуска одним файлом
├── artifacts/           результаты запусков
└── reports/             среда, журналы запусков, сравнения контрольных сумм
```

## Принципы

1. **Один конфиг — один запуск.** Все параметры эксперимента лежат в `configs/`,
   а не зашиты в код по месту. Скрипт читает конфиг, манифест повторяет его поля.
2. **Артефакт без манифеста не является результатом.** Рядом с каждым файлом
   результата лежит `manifest.json` с моделью, ревизией, prompt, seed, параметрами
   инференса, устройством, dtype, версиями библиотек и SHA-256.
3. **Ревизия модели фиксируется всегда.** Имя модели без `revision` указывает на
   подвижный снимок и не даёт воспроизводимости.
4. **Кэш весов и виртуальное окружение в репозиторий не попадают** — они
   восстанавливаются из `reports/environment.txt` и конфига.
5. **Отрицательный результат фиксируется, а не прячется.** Расхождение контрольных
   сумм, конфликт зависимостей и воспроизведённая ошибка — такие же артефакты,
   как и картинка.

## Инструменты

Для запуска моделей курс допускает [engee.com](https://engee.com),
[Hugging Face](https://huggingface.co), [Ollama](https://ollama.com) и OpenCLAW.
В каждой работе фактически использованная площадка указывается в отчёте.
В ЛР №1 использован локальный инференс на собственной машине через
Hugging Face Diffusers.

## Лицензии и ограничения

Код в репозитории учебный. Модели и их веса распространяются на условиях своих
лицензий; ссылки и ограничения указаны в отчёте соответствующей работы.
Сгенерированные изображения являются учебными концептами и не документируют
реальные объекты, события или системы.
