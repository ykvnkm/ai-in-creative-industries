# Происхождение и разбор prompt — вариант 11

## Контекст варианта (из методических указаний, стр. 7)

| Поле | Содержание |
| --- | --- |
| Контекст | Иллюстрация для материала о кибербезопасности |
| Изменяемый фактор / решение | Метафора защиты без интерфейсных клише |
| Обязательная проверка | Запустить и провалидировать артефакты |
| Артефакт | Иллюстрация и JSON |
| Критерий результата | Метафора объяснена в отчёте |
| Ограничение или риск | Не показывать реальные секреты и ключи |

## Авторство и входные данные

Prompt составлен автором работы. Использован только авторский текст: персональные
данные, закрытые брифы, клиентские материалы, товарные знаки, изображения реальных
людей и любые реальные ключи, пароли или фрагменты конфигураций не использовались
и не запрашивались.

## Итоговый prompt

```
abstract editorial illustration of layered protection, a smooth matte stone core
enclosed by several concentric translucent glass shells, neutral seamless studio
backdrop, deep teal and pale sand palette, centered symmetrical composition with
wide empty margins, soft diffused light, no text, no logo, no people, no padlock,
no shield emblem, no binary code, no user interface
```

## Четыре обязательных элемента

| Элемент | Формулировка в prompt | Зачем |
| --- | --- | --- |
| Объект | `a smooth matte stone core enclosed by several concentric translucent glass shells` | Носитель метафоры: ядро и несколько последовательных проницаемых оболочек |
| Среда | `neutral seamless studio backdrop`, `soft diffused light` | Убирает повествовательный контекст, оставляет объект единственным носителем смысла |
| Палитра | `deep teal and pale sand palette` | Холодный «технологический» тон против тёплого нейтрального; без сигнальных красного и зелёного, чтобы не считывалось как индикатор статуса |
| Композиция | `centered symmetrical composition with wide empty margins` | Симметрия поддерживает идею равномерной защиты со всех сторон; поля оставляют место под редакционную вёрстку |

## Выбранная метафора и обоснование

Метафора — **эшелонированная защита (defense in depth)**: ценность помещена внутрь,
вокруг неё несколько независимых полупрозрачных слоёв. Полупрозрачность выбрана
намеренно: каждый отдельный слой не является непроницаемым, защиту обеспечивает
их последовательность. Это соответствует реальной модели безопасности лучше, чем
образ «непробиваемого барьера».

## Интерфейсные клише, исключённые сознательно

Изменяемый фактор варианта — отказ от клише. В prompt внесены явные запреты, а сам
предметный ряд выбран так, чтобы клише было нечем породить:

- навесной замок и замочная скважина (`no padlock`);
- геральдический щит (`no shield emblem`);
- «цифровой дождь» и двоичный код (`no binary code`);
- элементы интерфейса, окна, HUD, терминалы (`no user interface`);
- фигура «хакера в капюшоне» (`no people`);
- надписи и логотипы (`no text`, `no logo`).

## Ограничение метода, которое нужно учитывать

SD Turbo работает с `guidance_scale=0.0` и не использует negative prompt. Запреты
вида `no padlock` включены в основной текст и поэтому не гарантированы: они лишь
смещают распределение. Фактическое отсутствие клише проверяется визуально по
полученному артефакту и фиксируется в отчёте, а не постулируется заранее.

## Проверка безопасности prompt

- [x] нет реальных лиц и узнаваемых людей;
- [x] нет товарных знаков и логотипов;
- [x] нет закрытых или клиентских материалов;
- [x] нет реальных ключей, паролей, токенов и фрагментов конфигураций;
- [x] нет утверждения, что изображение документирует реальную систему защиты.
