# ЛР №1. Подготовка рабочей среды и паспорт воспроизводимого AI-эксперимента

**Вариант 2** · статус: **не начата**

## Что требуется

Подготовить изолированную среду Python, зафиксировать условия эксперимента в
паспорте и доказать воспроизводимость **измерением**, а не утверждением.
Генеративная модель здесь не используется: работает учебный генератор
процедурных текстур, выданный преподавателем (`src/`). Настоящие модели —
в ЛР №5.

## Вариант 2

Номер варианта раскладывается по правилу `N = (контекст − 1) × 6 + фактор`,
значит вариант 2 — это контекст 1 и фактор 2.

| | |
| --- | --- |
| Контекст | облачное небо (фон афиши) |
| Изменяемый фактор | число октав **+1** (`--factor octaves`) |
| Параметры контекста | шаг решётки `cell` 32, октав 4, затухание 0,50 |
| Базовый seed / число seed | 101 / 5 |
| Критерий существенности | \|Δ\| > 2s, **порог записывается до запуска** |
| Риск варианта | новая октава берёт следующие числа последовательности; проверить, что диапазон яркости сохраняется после нормировки |

Команда запуска из методички:

```bash
python src/lab01_experiment.py --variant 2 --out artifacts/v02
```

## Что нужно сдать

1. Протокол воспроизводимости: четыре запуска по схеме seed `101, 101, 1101, 101`,
   ожидается `EQ_1_2 = true`, `EQ_1_4 = true`, `EQ_1_3 = false`, `EQ_2_4 = true`.
   Сравниваются отпечатки **полных массивов пикселей**, а не средние и не PNG.
2. Таблица четырёх метрик (среднее яркости, контраст, граничная энергия, энтропия)
   с базой, фактором, Δ и \|Δ\|/s при n = 5.
3. Вывод по каждой метрике в формулировке «существенно / не обнаружено при n = 5».
4. Паспорт эксперимента: цель и критерий, данные, модель, параметры, среда
   (включая версии Python и `zlib`), процедура, результаты, ограничения.
5. Пара изображений seed 101 (база и фактор) в одном масштабе.
6. Намеренная ошибка: запуск без `--seed` даёт разные отпечатки — симптом,
   диагностика, исправление.
7. Журнал эксперимента: дата, исполнитель, команды, наблюдения.

Часть Б (рабочая область Engee) выполняется **по указанию преподавателя**:
версии среды и кабинета, `VERSION` и `versioninfo()`, поведение панели
«Переменные» после очистки и перезапуска ядра.

## Важное из методички

- Гипотеза и порог записываются **до** запуска; изменение порога после просмотра
  результатов — нарушение методики и критическая ошибка.
- Выборочное стандартное отклонение считается с делителем `n − 1`.
- Отпечаток PNG может отличаться при одинаковых пикселях из-за версии `zlib` —
  это записывается в паспорт, а не считается ошибкой.
- Сторонние пакеты не нужны, `requirements.txt` останется пустым; в паспорте
  это фиксируется фразой «сторонние пакеты не используются».
- Критические ошибки, при которых работа не принимается: результат без записи
  seed; сравнение воспроизводимости по среднему вместо полного массива; порог
  изменён после просмотра результата; выводы без данных запусков.
