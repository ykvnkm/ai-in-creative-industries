# Приложение А. Прогон демонстрационного примера методических указаний

## Что это

Каталог содержит **не основную работу по варианту 11**, а отдельный прогон
демонстрационного примера из методических указаний (prompt про афишу научного
фестиваля), выполненный **в другой среде**: контейнер Linux x86-64, Python 3.12.14,
PyTorch 2.7.1+cpu.

Основная работа по варианту 11 выполнена локально на Apple M4 и лежит в
`LR01/artifacts`, `LR01/reports`, `LR01/configs`.

## Зачем приложение оставлено

Приложение используется в отчёте как материал для анализа **границ
воспроизводимости**: оно позволяет сопоставить два независимых CPU-окружения
(Linux x86-64 и macOS arm64) и показать, что побитовое совпадение ожидается внутри
одной зафиксированной среды, а не между платформами.
